# Telegram AI Bot с памятью и контролем уверенности

Умный Telegram-бот на базе локальной LLM (llama.cpp / Ollama). Умеет не просто отвечать, а запоминать факты о пользователе, искать по заметкам и честно говорить, насколько он уверен в ответе.

# Цель проекта

Языковые модели обучены генерировать ответы, но убедительный ответ не всегда означает достоверный. Когда модели не хватает знаний или контекста, она может заполнить пробелы правдоподобными, но вымышленными деталями — галлюцинациями.

В основе проекта — механизм контролируемой неопределённости: вместо того чтобы отвечать любой ценой, ассистент оценивает уверенность в своём ответе и при низком значении запрашивает уточнение. Постоянная память о пользователе дополняет этот подход: важные факты и заметки сохраняются между обращениями и помогают восполнять недостающий контекст.

Цель — не заставить модель знать всё, а научить её вовремя останавливаться, обозначать сомнения и задавать вопросы вместо догадок.

Самооценка уверенности — не гарантия достоверности и не измеренная вероятность правильного ответа. Это дополнительный сигнал для выбора между ответом и уточняющим вопросом.

# Главные фишки

- **Память о пользователе**: автоматически сохраняет важные факты в `[CORE]` и заметки в `[NOTE]`.
- **Поиск по контексту**: перед ответом анализирует старые заметки и подтягивает релевантную информацию.
- **Контроль уверенности**: модель обязана указать `[CONFIDENCE: X]`. Если уверенность ниже 70 — бот не выдумывает, а задаёт уточняющий вопрос.
- **Защита от галлюцинаций**: строгие правила в системном промпте + парсинг служебных тегов.
- **Безопасность**: токены и данные пользователей не хранятся в коде, вынесены в переменные окружения.

##  Быстрый старт

1. Подготовка окружения


pip install pyTelegramBotAPI requests python-dotenv


2. Настройка переменных


Создай файл .env в папке с проектом (он не попадёт на GitHub благодаря .gitignore):

env
BOT_TOKEN=123456:ABC-DEF...
LLM_URL=http://127.0.0.1:8080/v1/chat/completions
MODEL_NAME=local-model
Важно: Никогда не коммить реальный токен в репозиторий. В коде стоит защита: если токен равен "YOUR_TOKEN", бот не запустится.



3. Запуск
bash
python bot.py


### Как работает память?
Бот использует два типа памяти:

Ядро (core) — важные факты о пользователе (имя, город, предпочтения). Добавляются автоматически по тегу [CORE: ...] или вручную командой /remember.
Заметки (notes) — контекст прошлых разговоров. Автоматически сохраняются по тегу [NOTE: ...]. Хранится до 200 последних заметок.
Команды для управления памятью
Команда	Что делает
/start	Приветствует и сбрасывает текущее уточнение (память остаётся)
/reset	То же, что /start — сбрасывает только состояние уточнения
/remember <текст>	Вручную добавляет факт в ядро памяти
/profile	Показывает текущие факты и последние 10 заметок
Требования к LLM
Чтобы бот работал корректно, твоя локальная модель должна соблюдать формат ответа:

В начале ответа обязательно писать: [CONFIDENCE: число] (число 0–100).
Важные факты о пользователе оформлять как: [CORE: факт].
Контекст и пояснения оформлять как: [NOTE: заметка].
Все теги должны быть закрыты квадратной скобкой ].
Пример правильного ответа модели:

text
[CONFIDENCE: 85]
Ты живёшь в Москве, это я запомнил. Давай расскажу про погоду.
[CORE: пользователь живёт в Москве]
[NOTE: обсуждали погоду в Москве]
Если модель не следует этому формату, парсер не сможет извлечь уверенность и память.

#### Структура проекта
bot.py — основная логика бота и парсинг ответов.
.gitignore — исключает из коммита токены, профили и временные файлы.
requirements.txt — зависимости для установки.
profiles.json — база памяти пользователей (генерируется автоматически).


##### Безопасность и рекомендации
Файл profiles.json содержит личные данные пользователей. Не выкладывай его на GitHub.
Если токен бота был случайно скомпрометирован, сразу отзывай его через @BotFather командой /revoke.
Для продакшена лучше использовать приватный репозиторий и запускать бота на VPS с изолированным окружением.
